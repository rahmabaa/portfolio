# Rahma Ben Attia — Portfolio

Portfolio professionnel React + Vite pour Rahma Ben Attia, Développeuse Full Stack — PHP / Symfony.

## Contenu

- Profil et présentation
- Compétences techniques
- 5 expériences/projets : TRANSTU, InfraDev, InSpark, SONEDE et AGIL
- Formation
- Langues
- Contact

## Installation

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```
